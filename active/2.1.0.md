# 2.1.0

- Status: In progress
- Core: `2.1.0-dev`
- Extensions: `2.1.0-dev`
- Owner: Release team
- Depends on: `2.0.0.0`

## Objective

Stabilize the post-fork runtime, finish security and compatibility hardening,
and establish a documented baseline before the 3.0 cleanup.

## Core Workstreams

- [x] Remove the retired Admin module and stale repository references.
- [x] Add Studio API token protection and package the generated static UI.
- [x] Add SSRF, local-path, output-size, timeout, and executor lifecycle guards.
- [x] Add regression coverage for filesystem, Nacos lifecycle, observation, and
  execution boundaries.
- [ ] Classify remaining open issues into blocker, should-fix, and post-2.1.0 work.
- [ ] Publish the 2.1.0 migration and compatibility guide.
- [ ] Run the Core release matrix on supported JDK and Spring Boot versions.
