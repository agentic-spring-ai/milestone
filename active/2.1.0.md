# 2.1.0

- Status: In progress
- Core: `2.1.0-dev`
- Extensions: `2.1.0-dev`
- Owner: Release team
- Depends on: `2.0.0.0`

## Objective

Stabilize the post-fork runtime, finish security and compatibility hardening,
and establish a documented baseline before the 3.0 cleanup.

## Core Workstreams

- [x] Remove the retired Admin module and stale repository references.
- [x] Add Studio API token protection and package the generated static UI.
- [x] Add SSRF, local-path, output-size, timeout, and executor lifecycle guards.
- [x] Add regression coverage for filesystem, Nacos lifecycle, observation, and
  execution boundaries.
- [x] Classify remaining open issues into blocker, should-fix, and post-2.1.0 work.
  See [2.1.0 issue triage](2.1.0-triage.md).
- [x] Publish the 2.1.0 migration and compatibility guide.
- [x] Run the Core release matrix on supported JDK 17 and JDK 21 with the
  Spring Boot 4.1.0 baseline. The matrix is enforced by CI compilation and
  has been run locally with full tests.

## Current Release Blockers

The implementation baseline is complete, but the milestone is not a published
release yet. The release team still needs to:

- complete per-artifact replacement evidence for Extensions candidates;
- run an actual upgrade/rollback rehearsal;
- publish matching Core and Extensions 2.1.0 artifacts and checksums.

The local source-compatibility command is documented in
[`docs/2.1.0-migration.md`](https://github.com/agentic-spring-ai/agentic-spring-ai/blob/main/docs/2.1.0-migration.md)
and implemented by
[`verify-extensions-compatibility.sh`](https://github.com/agentic-spring-ai/agentic-spring-ai/blob/main/tools/scripts/verify-extensions-compatibility.sh).
