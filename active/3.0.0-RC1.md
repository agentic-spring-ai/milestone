# 3.0.0.0-RC1

- Status: Planned
- Core: `3.0.0.0-RC1`
- Extensions: `3.0.0.0-RC1`
- Owner: Release team
- Depends on: `2.1.0`

## Objective

Deliver a deliberately smaller 3.x release candidate after the 2.1.0 baseline
is stable. Scope must be evidence-based: no module is removed solely because a
newer model API exists.

## Core

- [x] Remove the retired Admin module.
- [ ] Finish the remaining 2.x issue triage and identify RC1 blockers.
- [ ] Review public API and configuration compatibility.
- [ ] Update BOMs, examples, documentation, and release notes together.
- [ ] Run upgrade and rollback verification from the latest 2.1.0 release.

## Extensions

- [ ] Inventory exact DashScope tool-call artifacts and consumers.
- [ ] Inventory every document parser and reader artifact and its consumers.
- [ ] For each candidate, choose `Keep`, `Deprecate`, `Remove`, or `Move`.
- [ ] Provide a replacement and migration example for every deprecated/removed artifact.
- [ ] Apply a deprecation window before deleting publicly consumed artifacts
  unless a breaking removal is explicitly approved.
- [ ] Verify the Extensions BOM against Core and supported Spring AI versions.

## Release Gates

- [ ] RC scope is frozen and every removal has an owner and migration note.
- [ ] All Critical/High issues are closed or explicitly accepted by the
  release team.
- [ ] Core/Extensions integration matrix passes.
- [ ] Maven Central RC artifacts, checksums, and source/javadoc artifacts are published.
- [ ] Release notes include breaking changes and rollback instructions.
