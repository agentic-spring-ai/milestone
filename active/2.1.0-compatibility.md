# 2.1.0 Compatibility Matrix

This matrix records source-level verification for the `2.1.0-dev` development
line. It is not a substitute for publishing and consuming signed release
artifacts.

## Dependency Baseline

| Component | Version |
| --- | --- |
| Core | `2.1.0-dev` |
| Extensions | `2.1.0-dev` |
| Java | 17, 21 |
| Spring Boot | 4.1.0 |
| Spring AI | 2.0.0 |
| MCP SDK | 2.0.0 |
| A2A SDK | 0.2.5.Beta2 |

## Verified Combinations

| Core | Extensions | Java | Result |
| --- | --- | --- | --- |
| 2.1.0-dev | 2.1.0-dev source install | 17 | Full Maven tests passed |
| 2.1.0-dev | 2.1.0-dev source install | 21 | Compile + tests passed |
| 2.1.0 release dry-run | 2.1.0 release dry-run | 17 | Package passed |

The Extensions source reactor contains 143 modules. The local compatibility
check installs that reactor first, then runs Core tests against the installed
`2.1.0-dev` artifacts:

```bash
tools/scripts/verify-extensions-compatibility.sh \
  /path/to/agentic-for-spring-ai-extensions
```

## Not Yet Verified

- Published Core/Extensions `2.1.0` artifacts and checksums.
- A clean consumer build that resolves `2.1.0-dev` from a remote repository.
- Upgrade and rollback against a released `2.0.0.0` deployment.
- Spring Boot versions other than `4.1.0`.

## Acceptance

The matrix can be marked release-complete only after the published artifact
rows and the upgrade/rollback rows are executed and attached to the release
record.

The Extensions BOM now uses the CI-friendly `${revision}` property, so
`-Drevision=2.1.0` produces a consistent BOM and reactor version during release
dry-runs.
