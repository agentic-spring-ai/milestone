# 2.1.0 Extensions Inventory

The Extensions repository currently contains 143 modules on `main` at
`2.1.0-dev`. This is a classification for the 2.1.0 baseline, not a deletion
list. No public Extensions artifact is removed in 2.1.0.

## Keep

These modules are consumed by Core POMs or examples and remain required for the
2.1.0 compatibility baseline:

- `agentic-spring-ai-starter-dashscope`
- `agentic-spring-ai-starter-document-parser-tika`
- `agentic-spring-ai-starter-document-parser-markdown`
- `agentic-spring-ai-starter-document-parser-bshtml`
- `agentic-spring-ai-starter-document-parser-yaml`
- `agentic-spring-ai-mcp-registry`
- `agentic-spring-ai-observation`

Platform modules for memory, vector stores, MCP, models, prompt, and RAG also
remain available. Their ownership and usage should be reviewed before any 3.0
removal proposal.

## Deprecate Candidates

These public artifact families are not removed in 2.1.0. They require usage
evidence, a replacement, and a documented deprecation window before a 3.0
decision:

- 9 `document-parsers` modules
- 23 `document-readers` modules
- 43 `tool-calls` modules

The exact artifact names are listed by the Extensions reactor POM. A candidate
without a confirmed consumer is still not safe to delete because users may
depend on it directly.

## Remove / Move

- Remove: none in 2.1.0.
- Move: none in 2.1.0.

Any future Remove or Move proposal must name the artifact, consumer scan, target
location, replacement, migration example, and deprecation timeline.

## Evidence

- Core imports the Extensions BOM and uses the seven Keep modules above.
- Extensions `main` is `2.1.0-dev`; published tags remain `v1.1.2.4` and
  `v2.0.0.0`.
- The full Extensions reactor builds and installs locally with Maven, and Core
  tests pass against the installed `2.1.0-dev` artifacts.
