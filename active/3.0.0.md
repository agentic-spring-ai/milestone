# 3.0.0.0

- Status: Planned
- Core: `3.0.0.0`
- Extensions: `3.0.0.0`
- Depends on: `3.0.0.0-RC1`

## Objective

Promote the RC1 contract to a stable release after compatibility feedback,
release validation, and documentation are complete.

## Release Gates

- [ ] RC1 feedback is triaged and all release blockers are closed.
- [ ] Public APIs, configuration keys, and BOM coordinates are frozen.
- [ ] Core and Extensions pass the supported-version compatibility matrix.
- [ ] Upgrade from 2.1.0 and rollback to the previous stable line are verified.
- [ ] Migration documentation covers every removed or deprecated artifact.
- [ ] Release artifacts, checksums, source, javadoc, and signed notes are published.

## Promotion Rule

Do not mark this milestone released until the RC1 document has no unchecked
Critical/High gate and the two repositories publish matching release notes.
